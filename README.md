# Alayna's Birthday Quest 💜

A mobile-first interactive birthday experience made for Alayna by Uncle John.

Alayna discovers five pieces of her own magic — Curiosity, Courage, Kindness, Imagination, and Strength — before making a birthday wish and unlocking a personal letter.

This is a zero-build static site. For GitHub Pages, deploy from the `main` branch at `/ (root)`.
